# Search

Chikamichi searches across histories, bookmarks, and tabs by default. Prefix commands narrow the target when you know exactly where to look.

## Search prefixes

| Prefix | Target                      |
| ------ | --------------------------- |
| `/h`   | Search only browser history |
| `/b`   | Search only bookmarks       |
| `/t`   | Search only open tabs       |

Examples:

```text
/h vitepress
/b github
/t dashboard
```

## Opening results

| Shortcut                | Action                                      |
| ----------------------- | ------------------------------------------- |
| `Enter`                 | Open the selected URL                       |
| `Ctrl + Enter`          | Open with the alternative open action       |
| `↓` / `↑`               | Move selection                              |
| `Ctrl + N` / `Ctrl + P` | Move selection without leaving the home row |

The alternative open action can be configured in Settings. It can open links in the current tab or a new tab depending on your preference.

## Favorites

Use `Ctrl + F` to pin the selected item as a favorite. Favorites appear in the initial view so repeated destinations are immediately available.

Favorite items can be reordered from the popup UI.
