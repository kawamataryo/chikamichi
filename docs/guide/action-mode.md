# Action Mode

Action Mode runs commands against the current page. Type `>` in the search input to switch from search results to page actions.

## Available actions

| Action                         | What it does                               |
| ------------------------------ | ------------------------------------------ |
| Copy Markdown Link             | Copies the current page as a Markdown link |
| Copy URL                       | Copies the current page URL                |
| Copy Title                     | Copies the current page title              |
| Mute / Unmute Tab              | Toggles audio for the current tab          |
| Pin / Unpin Tab                | Toggles pinned state for the current tab   |
| Duplicate Tab                  | Opens a duplicate of the current tab       |
| Capture Visible Area           | Saves the visible area to Downloads        |
| Copy Visible Area to Clipboard | Copies the visible area screenshot         |
| Capture Full Page              | Saves a full-page screenshot to Downloads  |
| Copy Full Page to Clipboard    | Copies a full-page screenshot              |

## When to use it

Action Mode is useful for small browser tasks that usually require a menu, extension button, or manual copy step. The highest-frequency actions are available from the same popup used for search.

![Chikamichi popup Action Mode](/screenshots/popup-action-mode.png)

```text
> markdown
> copy url
> screenshot
```

Screenshot actions only run when explicitly selected.
