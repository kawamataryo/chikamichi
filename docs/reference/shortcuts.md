# Keyboard Shortcuts

| Shortcut                | Action                                 |
| ----------------------- | -------------------------------------- |
| `Alt + K`               | Open Chikamichi                        |
| `↓` / `↑`               | Select next or previous result         |
| `Ctrl + N` / `Ctrl + P` | Select next or previous result         |
| `Enter`                 | Open the selected URL                  |
| `Ctrl + Enter`          | Open using the alternative open action |
| `Ctrl + F`              | Add or remove favorite                 |
| `Ctrl + C`              | Copy URL to the clipboard              |
| `>`                     | Enter Action Mode                      |

## Commands

| Command | Action           |
| ------- | ---------------- |
| `/h`    | Search histories |
| `/b`    | Search bookmarks |
| `/t`    | Search tabs      |
